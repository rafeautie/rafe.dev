# Credits

The guns are from Quaternius' [Ultimate Gun Pack](https://quaternius.com),
released under CC0 (free for any use). Each was scaled to its real length and
compressed, and the scope was taken off the rifle used for the M14.

| Game      | Model            |
| --------- | ---------------- |
| M1911     | Pistol_2         |
| Olympia   | Shotgun_SawedOff |
| M14       | SniperRifle_6    |
| MP5       | SubmachineGun_2  |

| Remington | Shotgun_3        |
| Galil     | AssaultRifle_4   |
| Python    | Revolver_2       |
| RPD       | AssaultRifle_2   |

The Ray Gun, the hands and the knife are built in code.

The textures are from [Poly Haven](https://polyhaven.com), also CC0, shrunk
to 256 pixels in WebP: walnut_veneer_02 (wood), rusty_metal_02 (wear on the
metal), rough_linen (sleeves) and fabric_leather_02 (gloves).
